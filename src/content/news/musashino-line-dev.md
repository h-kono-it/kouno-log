# 武蔵野線.dev を立ち上げます

武蔵野線沿線の地域ITコミュニティ **[武蔵野線.dev](https://musashino-line.connpass.com/)** を始めます。初回は「クロスコミュニティ交流会 vol.1」として開催します。

## イベント情報

| | |
|---|---|
| 開催日 | 2026年9月23日（水・秋分の日） |
| 会場 | 朝霞市産業文化センター |

**[申し込みはこちら →](https://musashino-line.connpass.com/event/401818/)**

## どういう会か

**参加者同士の交流を軸に**した会です。LTなどのトークセッションは基本的にやりません。かわりに **OST（オープン・スペース・テクノロジー）** を採用して、その場に来た人が話したいテーマを持ち寄る形にしています。

「武蔵野線.dev」という名前ですが、これは特定の一地域のコミュニティというより、**沿線の複数の地域コミュニティが集まる横断的な枠組み**として考えています。

## なぜ始めるのか

きっかけは、多摩.dev・東葛.dev・埼京.dev の主催者同士でSNS上で話していたことでした。多摩と東葛のちょうど中間あたりということで埼玉南西部での開催を検討し、[埼京.dev](https://sai-kyo.connpass.com/) に声をかけて実現しています。

東京のベッドタウンという意味では、どの地域も似た課題を抱えています。ただ、ひとつのコミュニティを続けていると、どうしても顔ぶれと話題が固定されてきます。**横の地域性を感じつつ、少し違うバックグラウンドを持つ人と話す場**がほしかった、というのが立ち上げの動機です。
