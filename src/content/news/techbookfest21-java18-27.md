## どんな本か

![Java 10+a年振り返り（下巻）書影、タイトルと妻が描いたシマエナガ3羽のイラスト](./images/hyoushi-gekan.webp)

Java 18からJava 27までの主な新機能を、バージョンごとにまとめた本です。[上巻](https://techbookfest.org/product/fiphWJLZvYRKCvCZ7Hzc1h)で扱ったJava 8〜17の続きにあたります。

上巻の範囲がモダンJavaへの助走だったとすれば、下巻はその到達点です。上巻で別々の機能として紹介したRecordsとSealed Classesは、Java 21でパターンマッチングと1つに合流しました。長く構想が語られてきたVirtual Threadsが正式な機能になったのも、同じJava 21です。

上巻を読んでいなくても読み進められるように書いています。

## 構成

| 章 | 内容 |
| --- | --- |
| Javaとは | JEPの読み方、Preview機能という仕組みなど、本編を読むための前提 |
| OpenJDKの主要プロジェクト | 長期プロジェクトの成果が本編のどの章に現れるかの地図 |
| Java 18 〜 Java 27 | 各バージョンの主な新機能。末尾に「Previewとincubatorの進捗」を置いて統一 |
| この先のJava | ここまでの変化がどこへ向かっているのかの整理 |

バージョン順に進むので、1つのプロジェクトの成果が複数の章に散らばります。そのための地図として「OpenJDKの主要プロジェクト」の章を置きました。

上巻ではPreview段階の機能を原則として扱いませんでしたが、下巻はPreviewが正式化されていく過程そのものが読みどころなので、各章の末尾で追いかけています。

## こんな人におすすめ

- Java 17やJava 21を使っていて、次のLTSへの移行を考えている人
- 現場で使えるバージョンが固定されていて、「ここまでなら使える」を確認したい人
- Javaがどう進化してきたか、これからどこへ向かうのかを掴みたい人

## 書いてみて気づいたこと

上巻は「新しい機能が増えていく」話でしたが、下巻はそれと同じくらい **「古いものを畳む」話** が多くなりました。アプレットAPI、Security Manager、`sun.misc.Unsafe`のメモリアクセスメソッド、`Thread.stop()`。長く使われてきたものを安全に取り除く作業に、増やすのと変わらない労力が割かれています。

もう1つは、半年ごとのリリースサイクルの使い方です。Compact Object HeadersはJava 24で実験的機能、Java 25で製品機能、Java 27でようやくデフォルトになりました。ZGCの世代別化も3段階を踏んでいます。短いサイクルは「新機能が早く届く」ためのものだと思っていましたが、それ以上に **大きな変更を小さく刻んで安全に届ける** ために使われているのだと分かりました。

## 書いている途中で作ったもの

ZGCやCompact Object Headersの話を書いているうちに、自分がGCを雰囲気でしか理解していないことに気づきました。そのまま書き進めるのは気持ち悪かったので、執筆の途中でGCの勉強用サイトを作っています。

[Java GC（GCの基礎と、Serial GCからGenerational ZGCまでの年代記）](/news/java-gc/)

ヒープ図とStop-the-Worldのタイムラインを1フェーズずつ動かせるようにしたもので、下巻のGCまわりの章は、これを作ってから書き直した部分があります。
